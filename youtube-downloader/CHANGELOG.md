# 更新日志

所有更新都记录在此文件中。

## [1.0.0] - 2024-06-10

### 新增
- ✨ 首次发布
- 🎬 YouTube 视频下载功能
- 📊 支持多种分辨率选择（240p - 4K）
- 🎨 SwiftUI 现代用户界面
- 🔊 音频提取功能（MP3、M4A）
- 📝 视频信息显示
- ⚙️ 可配置的下载设置
- 🌐 代理支持
- 📁 自定义保存位置

### 功能
- YouTube URL 验证
- 实时下载进度显示
- 错误处理和提示
- 应用内设置管理
- 深色/浅色模式支持

### 已知问题
- 某些受地区限制的视频可能无法下载
- 极长的视频下载可能需要较长时间

### 依赖项
- Python 3.8+
- yt-dlp 2024.x+
- ffmpeg 6.0+

### 版本号说明

使用语义化版本控制 (Semantic Versioning):
- MAJOR.MINOR.PATCH
- 例如: 1.0.0
  - 1 = 主版本（大更新）
  - 0 = 次版本（新功能）
  - 0 = 修订号（Bug 修复）
